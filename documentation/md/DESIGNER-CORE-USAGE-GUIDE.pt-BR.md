# @jumentix/designer-core — guia de uso

`designer-core` ajuda frontends a validar e circular **documentos de design**
sem puxar dependências só de Node.

## Quando usar

- Você edita designs de domínio no browser.
- Precisa validar → exportar → reimportar sem servidor.
- Quer helpers compartilhados entre UI e PWA offline.

## Instalar

```bash
bun add @jumentix/designer-core
```
