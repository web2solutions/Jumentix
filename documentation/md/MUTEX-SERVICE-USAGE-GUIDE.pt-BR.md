# @jumentix/mutex-service — guia de uso

Locks nomeados evitam que dois workers mutem o mesmo recurso. Nos docs e testes,
use KV em memória.

## Instalar

```bash
bun add @jumentix/mutex-service @jumentix/key-value-storage
```
