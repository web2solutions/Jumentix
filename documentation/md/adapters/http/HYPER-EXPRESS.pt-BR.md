# Adaptador Hyper-Express

## Propósito

Use o Hyper-Express como adaptador REST de alto desempenho.

## Pontos de entrada

- `apps/backend-template/src/interface/HTTP/adapters/hyper-express/hyper-express.ts`
- `apps/backend-template/src/interface/HTTP/adapters/start-rest-api.ts`

## Crie um serviço com Hyper-Express

1. Mantenha os contratos/casos de uso do módulo inalterados.
2. Adicione manipuladores específicos do Hyper-Express.
3. Execute:

```bash
pnpm run dev:hyper-express
```

## Produção

```bash
pnpm run prod:hyper-express
```
