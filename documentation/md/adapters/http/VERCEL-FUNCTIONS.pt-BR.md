# Adaptador de funções Vercel

## Propósito

Expor operações de API por meio de manipuladores de funções no estilo Vercel (`req`/`res`).

## Pontos de entrada

- `apps/backend-template/src/interface/HTTP/adapters/vercel-functions/vercel-functions.ts`

## Construa um serviço com funções Vercel

1. Implementar lógica de controlador/caso de uso em módulos.
2. Implementar wrappers de manipuladores específicos da estrutura.
3. Execute:

```bash
bun run dev:vercel-functions
```
