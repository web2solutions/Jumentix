# Requirement 075 - Jumentix Composition Clarity in Specs

## Context

Jumentix is a composed product (libraries, tools, templates, components). This composition must be explicit in Spec Development Driven artifacts.

## Mandatory Rules

1. A canonical composition spec must define and classify these four asset groups.
2. Ownership boundaries and cross-type contracts must be explicit.
3. Composition spec must be linked from spec indexes and source maps.
4. Requirement and NFR registries must be synchronized.

## Acceptance Criteria

1. `documentation/md/SPEC-JUMENTIX-COMPONENT-SYSTEM.md` exists and is complete.
2. Spec indexes and coverage matrix map this composition model.
3. `.agents` requirement and NFR registries include this rule.
4. Project todo snapshot records this governance update.
