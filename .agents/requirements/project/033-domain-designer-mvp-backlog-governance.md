# Requirement 033 - Domain Designer MVP Backlog Governance

## Rules

1. Every Domain Designer MVP idea is created and maintained as a Linear issue in
   its focused Linear project.
2. Linear is the only repository planning record; no local TODO mirror is
   maintained.
3. A completed item moves to Done only after delivery gates and the final Linear
   project update are complete.
4. Documentation remains mandatory for each delivered Domain Designer feature.

## Implementation Notes

- Backlog tracking is part of delivery quality, not optional project metadata.
- The delivered/current roadmap is `documentation/md/DOMAIN-DESIGNER-MVP-ROADMAP.md`.
