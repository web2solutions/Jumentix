# Requirement 074 - Security and Compliance Practices Must Be in Specs

## Context

Security and compliance practices must be explicitly represented in Spec Development Driven artifacts.

## Mandatory Rules

1. Security/compliance execution standards must exist in a dedicated spec document.
2. The document must be indexed in canonical spec indexes and source maps.
3. The coverage matrix must include security/compliance practice mapping and enforcement.
4. Requirement and NFR registries must be synchronized.

## Acceptance Criteria

1. `documentation/md/SPEC-SECURITY-AND-COMPLIANCE-PRACTICES.md` exists.
2. Spec indexes link to this artifact.
3. Agents registry references this requirement.
4. Project todo snapshot records this governance update.
