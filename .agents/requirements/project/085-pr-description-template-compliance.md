# Requirement 085 - PR Description Template Compliance

## Context

Pull requests need consistent context and governance metadata so reviewers can evaluate scope, risks, acceptance criteria, and project traceability quickly.

## Requirement

1. PR descriptions are mandatory for every pull request.
2. PR descriptions must follow the repository PR template format.
3. Required template sections must be fully filled; placeholders and empty sections are not allowed.
4. PRs that do not follow the template must be blocked from approval until fixed.

## Acceptance Criteria

1. Governance docs explicitly require PR descriptions for all PRs.
2. Governance docs explicitly require PR template compliance.
3. Review flow rejects PRs with missing or non-compliant descriptions.
