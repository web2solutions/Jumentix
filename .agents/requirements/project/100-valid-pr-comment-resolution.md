# Requirement 100 - Valid PR Comment and Thread Resolution

Every valid pull-request comment is a mandatory merge blocker. Before merge,
the accountable agent must implement the correction, run applicable required
gates, and record resolution evidence. A comment may be treated as invalid only
with a factual PR explanation; unresolved valid comments must never be bypassed.

No PR may be merged while GitHub review threads, code comments, or discussion
threads remain unresolved. The merge owner must verify that every thread is
resolved or explicitly answered as invalid/non-actionable with evidence in the
PR before merge.
