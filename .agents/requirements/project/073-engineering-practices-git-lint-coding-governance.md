# Requirement 073 - Engineering Practices: Git, Commit Messages, Lint, and Coding Best Practices in Specs

## Context

Project engineering requirements (Git usage, commit message standards, lint discipline, and coding best practices) must be represented in Spec Development Driven resources.

## Mandatory Rules

1. Engineering execution rules must be documented in specs and linked from canonical spec indexes.
2. Git usage and traceability expectations must be explicit and auditable.
3. Conventional commit expectations must be explicit.
4. Lint, architecture checks, and coverage/security gates must be part of spec-defined merge readiness.
5. Coding best practices must remain bound to DDD + Event-Driven + Hexagonal constraints.

## Acceptance Criteria

1. Dedicated spec policy document exists and is indexed in Spec Development Driven docs.
2. Spec coverage matrix and source map include this policy.
3. Requirement registry and NFR registry are synchronized.
4. Project todo snapshot records completion of this governance requirement.
