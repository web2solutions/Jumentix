# @jumentix/key-value-storage — usage guide

Key/value storage is the shared port for caches, feature flags, and mutex
backends. Start with **InMemory** in the browser and tests; compile Redis only
in Node servers.

## Install

```bash
bun add @jumentix/key-value-storage
```

## Try the in-memory client

<DocsPlayground runtime="key-value-storage" id="getting-started" />

```js
const client = api.createInMemory();
await client.set('greeting', 'hello jumentix');
const value = await client.get('greeting');
```

## When to use which adapter

| Adapter | Environment | Notes |
| --- | --- | --- |
| InMemory | Browser demos, unit tests | Fast, not durable |
| Redis (Node) | Servers | Requires `redis` + env |
