# @jumentix/shared-contracts

Private placeholder for a future distributable workspace of shared OpenAPI and AsyncAPI contracts.

## Current `dev` status

This package contains no executable contract build yet and every lifecycle script reports a pending
migration wave. The canonical checked-in contracts remain:

- [`spec/1.0.0.yml`](https://github.com/web2solutions/aaa-typescript-boilerplate/blob/dev/spec/1.0.0.yml) for OpenAPI.
- [`spec/asyncapi/1.0.0.websocket.yml`](https://github.com/web2solutions/aaa-typescript-boilerplate/blob/dev/spec/asyncapi/1.0.0.websocket.yml) for WebSocket.
- [`spec/asyncapi/1.0.0.grpc.yml`](https://github.com/web2solutions/aaa-typescript-boilerplate/blob/dev/spec/asyncapi/1.0.0.grpc.yml) for gRPC.

Do not publish or import this placeholder as if it already owned those contracts.
