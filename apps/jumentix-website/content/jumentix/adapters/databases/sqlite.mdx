# SQLite Adapter

## Technology

Sequelize + SQLite profile for lightweight local persistence.

## Build Services with SQLite

1. Set env:

```bash
JUMENTIX_DATABASE_DRIVER=SQLite
JUMENTIX_DB_FILE=.tmp/jumentix.sqlite
```

2. Start API adapter.
