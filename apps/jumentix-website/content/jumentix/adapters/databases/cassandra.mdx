# Cassandra Adapter

## Technology

Cassandra driver profile.

## Build Services with Cassandra

1. Start container:

```bash
bun run docker:up:cassandra
```

2. Set env:

```bash
JUMENTIX_DATABASE_DRIVER=Cassandra
JUMENTIX_CASSANDRA_CONTACT_POINTS=127.0.0.1
JUMENTIX_CASSANDRA_KEYSPACE=aaa
JUMENTIX_CASSANDRA_PORT=9042
```

3. Start service adapter.
