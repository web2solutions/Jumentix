# Hyper-Express Adapter

## Purpose

Use Hyper-Express as high-performance REST adapter.

## Entrypoints

- `apps/backend-template/src/interface/HTTP/adapters/hyper-express/hyper-express.ts`
- `apps/backend-template/src/interface/HTTP/adapters/start-rest-api.ts`

## Build a Service with Hyper-Express

1. Keep module contracts/use cases unchanged.
2. Add Hyper-Express-specific handlers.
3. Run:

```bash
pnpm run dev:hyper-express
```

## Production

```bash
pnpm run prod:hyper-express
```
