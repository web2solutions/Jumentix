# Adaptador SQLite

## Tecnologia

Perfil Sequelize + SQLite para persistência local leve.

## Construa serviços com SQLite

1. Definir ambiente:

```bash
JUMENTIX_DATABASE_DRIVER=SQLite
JUMENTIX_DB_FILE=.tmp/jumentix.sqlite
```

2. Inicie o adaptador API.
