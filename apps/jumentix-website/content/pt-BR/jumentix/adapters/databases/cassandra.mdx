# Adaptador Cassandra

## Tecnologia

Perfil do motorista Cassandra.

## Crie serviços com Cassandra

1. Inicie o contêiner:

```bash
bun run docker:up:cassandra
```

2. Definir ambiente:

```bash
JUMENTIX_DATABASE_DRIVER=Cassandra
JUMENTIX_CASSANDRA_CONTACT_POINTS=127.0.0.1
JUMENTIX_CASSANDRA_KEYSPACE=jumentix
JUMENTIX_CASSANDRA_PORT=9042
```

3. Inicie o adaptador de serviço.
