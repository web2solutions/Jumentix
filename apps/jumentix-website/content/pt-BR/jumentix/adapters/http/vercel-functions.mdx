# Adaptador de funções Vercel

## Glossário

- **Adapter de entrada** — aceita chamadas de protocolo externo e traduz para use-cases.

## Responsabilidade no escopo

- **Camada:** adapter / http
- **Responsável por:** wiring específico deste framework/tecnologia
- **Usado com:** composição do backend-template, pacotes de persistência/SDK, guia correspondente
- **Não responsável por:** regras de domínio, autoría OpenAPI ou storage offline no browser

## Por que existe

A escolha de framework fica na borda. Este adapter mantém detalhes Express/Fastify/DB/realtime substituíveis.

## O que é

Adapter VERCEL FUNCTIONS para interfaces http do Jumentix — monta use-cases sem vazar tipos de framework no domínio.

## Propósito

Expor operações de API por meio de manipuladores de funções no estilo Vercel (`req`/`res`).

## Pontos de entrada

- `apps/backend-template/src/interface/HTTP/adapters/vercel-functions/vercel-functions.ts`

## Construa um serviço com funções Vercel

1. Implementar lógica de controlador/caso de uso em módulos.
2. Implementar wrappers de manipuladores específicos da estrutura.
3. Execute:

```bash
bun run dev:vercel-functions
```
