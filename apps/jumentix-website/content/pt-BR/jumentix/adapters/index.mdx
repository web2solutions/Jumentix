# Adaptadores

Adapters são a borda substituível do Jumentix. Eles recebem protocolo, runtime ou banco de dados, traduzem para contratos da aplicação e mantêm o domínio livre de detalhes de framework.

## Como escolher

1. Escolha o adapter HTTP que melhor combina com seu runtime de entrega.
2. Escolha o adapter de banco pelo modelo de dados, operação e smoke test disponível.
3. Use realtime quando o produto precisar de mensagens long-lived, streams ou comunicação entre clientes.
4. Mantenha regras de negócio em use cases; adapters só conectam o mundo externo.
