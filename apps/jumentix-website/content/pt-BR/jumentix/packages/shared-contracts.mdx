Placeholder privado para um futuro workspace distribuível de contratos OpenAPI e AsyncAPI.

O pacote ainda não possui build executável de contratos e todos os scripts informam uma onda de
migração pendente. Os contratos canônicos versionados continuam sendo:

- [`spec/1.0.0.yml`](https://github.com/XpertMinds/Jumentix/blob/dev/spec/1.0.0.yml) para OpenAPI.
- [`spec/asyncapi/1.0.0.websocket.yml`](https://github.com/XpertMinds/Jumentix/blob/dev/spec/asyncapi/1.0.0.websocket.yml) para WebSocket.
- [`spec/asyncapi/1.0.0.grpc.yml`](https://github.com/XpertMinds/Jumentix/blob/dev/spec/asyncapi/1.0.0.grpc.yml) para gRPC.

Não publique nem importe este placeholder como se ele já fosse proprietário desses contratos.
