                          Start your domain model
                          
            
                          
              This is the Domain Designer: model bounded contexts, entities and their fields,
              relationships, per-entity RBAC, message contracts and OpenAPI composition on a
              canvas with pan, zoom, snap, mini-map and undo/redo.
            
                          
            
                          
              First action: load the sample model — a small identity domain (Users and Organization,
              the same resources spec/1.0.0.yml declares) that exercises relationships,
              RBAC, a message contract and composition. Or type a domain name in the Domains panel
              and press Add to start from scratch.
            
                          
            
            
                          
              The sample is marked "sample" in the domain list and is safe to delete — it never mixes
              with your work. Once you have a model, run "Validate Model" in the Model Check panel;
              the export gate refuses exports while critical issues exist. Canvas controls are listed
              in the Legend panel (Space + drag to pan, Ctrl/Cmd + wheel to zoom).

                              Deploy Management
                              
        
                              Register and track deployment targets for monoliths, APIs, and function sets. Each target carries the Requirement 059 per-service metadata, validated against the deploy matrix. Targets can be edited in place and duplicated; a duplicate is an independent copy renamed by the " (copy)" rule.
                              
        
        
                              
          
                              No deployment targets yet
                              
          
                              
            This tab is a registry of deployment targets (dedicated servers, VMs, EC2, function
            providers), each carrying its Requirement 059 metadata and validated against the deploy
            matrix. It records where the service will run — it does not trigger deployments.
          
                              
          
                              First action: fill the target form below and press Add Target.
